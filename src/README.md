# Mergington High School Activities

A super simple website application that allows students to view and sign up for extracurricular activities.

## Features

- View all available extracurricular activities
- Sign up for activities
- Share any activity on Facebook, WhatsApp, or X, copy its direct link, or use your device's sharing options when available
- Shared links highlight and scroll to the activity after loading. Sharing includes only the activity name, public description, schedule, and link—not participant or teacher information. If copying is unavailable, select and copy the displayed link manually.
